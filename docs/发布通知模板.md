# 发布通知模板

- 对应文档：《SOP 模板版本发布流程》第 5 节
- 文档版本：1.0；交付日期：2026-11-25
- 每次正式发布与回滚都须发出通知；回滚通知须在决定回滚后 4 个工作小时内发出。
- 通知发出执行人：知识库管理员；内容最终责任人：SOP 负责人。
- 全部示例均为虚构数据，不含真实个人信息、企业信息与客户名称；联系人只写岗位角色，不写个人姓名与电话。

## 空白模板

```text
模板发布通知

模板名称：
版本号：旧版本 → 新版本
变更类型：主版本 / 次版本 / 文字修订
生效时间：____年__月__日 __:__

一、变更摘要
（本次改了什么，一句话说清；主版本须写明结构变化点）

二、影响角色与需要做的事
- 角色 A：需要做什么
- 角色 B：需要做什么

三、试运行情况（主版本必填，次版本填“不适用”）
- 试点会所：
- 试运行周期：
- 实例完成率：新版本 __%（旧版本 __%，变化 __ 个百分点）
- 实例超时率：新版本 __%（旧版本 __%，变化 __ 个百分点）
- blocker 级问题：无 / 有（说明）

四、回滚窗口
- 本次发布后 14 天（日历日）内可回滚，窗口截止：____年__月__日 24:00
- 触发条件：blocker 级问题；实例完成率较发布前下降超过 5 个百分点；
实例超时率较发布前上升超过 5 个百分点；合规或安全问题

五、联系人
- SOP 负责人（知识库工作台站内信）
- 知识库管理员（知识库工作台站内信）

附件：新版本全文链接、变更记录
```

## 已填写示例（虚构）

```text
模板发布通知

模板名称：会员入会办理
版本号：2.3 → 3.0
变更类型：主版本
生效时间：2027-02-02 09:00

一、变更摘要
新增执行步骤「核验企业营业执照有效期」，放在原第 2 步之后；
其余步骤内容不变，步骤编号顺延。

二、影响角色与需要做的事
- 前台接待：按新步骤核验营业执照有效期，有效期不足 30 天的转值班经理复核
- 值班经理：复核有效期不足 30 天的入会申请
- 一线执行代表：2 月 2 日前通读新版本第 2–4 步

三、试运行情况
- 试点会所：会所 A
- 试运行周期：2027-01-19 至 2027-02-01（2 周），实例 23 个
- 实例完成率：新版本 91%（旧版本 93%，下降 2 个百分点）
- 实例超时率：新版本 6%（旧版本 5%，上升 1 个百分点）
- blocker 级问题：无

四、回滚窗口
- 本次发布后 14 天（日历日）内可回滚，窗口截止：2027-02-15 24:00
- 触发条件：blocker 级问题；实例完成率较发布前下降超过 5 个百分点；
实例超时率较发布前上升超过 5 个百分点；合规或安全问题

五、联系人
- SOP 负责人（知识库工作台站内信）
- 知识库管理员（知识库工作台站内信）

附件：新版本全文链接、变更记录
```

## 回滚通知示例（虚构，标题与正文须标注「回滚」）

```text
模板回滚通知

模板名称：会员入会办理
版本号：3.0 → 恢复 2.3（3.0 已回滚、作废）
变更类型：回滚
生效时间：2027-02-05 10:00（即时生效）

一、回滚原因
试运行转正式后第 3 天出现 blocker 级问题：新步骤引用的证照核验接口
返回异常，导致 3 个实例无法继续。符合回滚触发条件 B1。

二、影响角色与需要做的事
- 前台接待：即时起按 2.3 版执行入会办理，不再执行新增的核验步骤
- 值班经理：复核已按 3.0 版发起、尚未完成的 3 个实例，按个案处理

三、后续安排
- 回滚报告将于 48 小时内出具
- 修复方案重新登记变更需求，从起草阶段重新走发布流程

四、联系人
- SOP 负责人（知识库工作台站内信）
- 知识库管理员（知识库工作台站内信）
```
